# 18. Security

Never expose:

- Database credentials
- API keys
- Payment secrets
- WhatsApp credentials

Frontend mein.

All secrets server-side environment variables mein hon.

Use:

- HTTPS
- Secure cookies
- CSRF protection where applicable
- Rate limiting
- Input validation
- Authentication
- Authorization
- Audit logging
